# PromptDecode/.github

The GitHub organisation profile for [promptdecode](https://promptdeco.de).

- `profile/README.md`: the page shown at [github.com/PromptDecode](https://github.com/PromptDecode)
- `assets/org-banner.png`: its banner, a copy of `assets/readme-banner.png` from
  [`website`](https://github.com/PromptDecode/website), rendered there by
  `tools/render-og.sh`. Re-copy it when it changes.
- `assets/org-avatar.png`: the organisation avatar, from the same script. GitHub
  has no API for it; upload by hand at
  `github.com/organizations/PromptDecode/settings/profile`.

Same house rule as the site: nothing is described as working unless it ships.
Today that is the decoder on the page, and nothing else.
